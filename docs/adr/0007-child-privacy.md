# 0007: No identifiable child data, ever

**Context.** The Learning Together track records how a child and a robot learn
alongside each other. The repo and site are public.

**Decision.**

- No child's name, face, voice, school, location or other identifying detail appears in the repo, the site, the database, or any public log.
- Learning Together publishes aggregates and anonymized observations only.
- Raw recordings involving a child stay off the lab's synced storage entirely.
- Front-matter schemas have no fields for a child's identity, by design.

**Consequences.** Some interesting material stays private. That is the point.
